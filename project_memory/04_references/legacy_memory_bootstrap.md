# Legacy Memory Bootstrap

Before `project_memory/` existed, AutoSniper used these first-generation repo memory files:

- `docs/ai_working_agreement.md`
- `task_plan.md`
- `findings.md`
- `progress.md`

They were useful, but they depended too much on an agent remembering to read them.

Those files now remain only as compatibility summaries during rollout. Durable project truth should be written into:

- constitution for project law
- machine rules for generated technical contracts
- state for current operational truth
- decisions for accepted durable choices
