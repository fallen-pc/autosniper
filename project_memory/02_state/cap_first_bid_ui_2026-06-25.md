# Cap-first bid UI wording

- AI Analysis already uses cap-first bid wording: max bid cap, profit at cap, current vs cap, and expected finish as a scenario guide.
- Missed Opportunities now mirrors that language for settled listings: max bid cap, sold vs cap, profit at sold price, and expected auction guide.
- Avoid reverting these surfaces to older labels like raw margin now, profit at expected finish, max bid limit, or projected profit as primary decision metrics.
