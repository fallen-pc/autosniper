# External Auction Intake And Repair Follow-Ups - 2026-07-11

- Added the external auction intake source slice to the repo: `scripts/scrape_external_auction_sources.py` plus regression coverage in `tests/test_external_auction_sources.py`.
- The scraper normalizes Pickles, Manheim, and Slattery detail text into the existing active-detail schema, tags discovered links with canonical coverage, filters to saved curve tags, and writes ignored CSV evidence under `output/external_auction_scrape/`.
- Pickles condition-detail rows now feed repair notes cleanly enough for the shared repair engine to classify missing tyres/wheels, windscreen pitting, flat batteries, and mechanical hard-avoid wording.
- Added repair quote follow-up helpers in `shared/repair_pricing_schedule.py`; follow-ups skip requests that already need photos/inspection/tyre size or have already been followed up.
- Model Accuracy now counts only manually logged sale outcomes, not purchase-history rows, when reporting logged outcomes and hit accuracy.
- Wired the external auction scrape into `scripts/scheduled_jobs.py --job daily` after the core Grays/Autotrader/master stages and before active AI revaluation. It writes combined daily outputs under `output/external_auction_scrape/daily` by default and can be disabled with `AUTOSNIPER_EXTERNAL_AUCTIONS_DAILY=0`.
- External saved-curve matches are now loaded by `ops.active_monitor` alongside Grays restricted active rows before `revalue_active_listings()` runs, so Pickles/Manheim/Slattery candidates use the same `run_curve_listing_analysis()` repair parsing, curve coverage, max-bid, and AI Analysis result path as Grays active cars without appending external rows into the Grays source CSVs.
- Missed Opportunities now appends external auction rows only when they have settled-sale evidence: a real price plus sold/closed status or date. Those rows then use the same sold-comps replay, repair-cost, max-bid, and miss-classification path as Grays sold rows. Active/upcoming external rows stay out of Missed Opportunities until the scraper can prove a settled result.
- Pickles detail parsing now maps terminal page evidence into the same sold-style fields used downstream by Grays: embedded `dateSold` becomes `status=Sold`, `date_sold`, and `time_remaining_or_date_sold`; visible `No longer available` marks the row sold/terminal without fabricating a sale price. Generic Pickles boilerplate such as "sold unregistered" is intentionally ignored as sale evidence.
- Daily external auction scraping now reseeds from prior saved-curve match URLs under `output/external_auction_scrape/` so known Pickles/Manheim/Slattery curve candidates keep being rechecked after they disappear from active search pages. The seed scope is curve matches only to avoid re-scraping irrelevant non-curve evidence.
- Daily source caps are intentionally source-specific: Pickles defaults to 20 list pages/all selected details, Manheim to 1 list page per configured location/25 selected details, and Slattery to the current category/all selected details. The caps can be tuned with `AUTOSNIPER_EXTERNAL_PICKLES_*`, `AUTOSNIPER_EXTERNAL_MANHEIM_*`, and `AUTOSNIPER_EXTERNAL_SLATTERY_*` env vars.
